# 對手停在 2♠，要不要重開賭倍：一萬副牌的雙夢家模擬資料

文章：[對手停在 2♠，單張黑桃的 11 點要不要重開賭倍？](https://hackmd.io/@TpKotoba/rkRPQFWAzg)。北家發牌，南北無身價、東西有身價，南家固定 ♠3 ♥9754 ♦AKT8 ♣A764，叫牌 Pass–1♠–賭倍–Pass–1NT–2♥–Pass–2♠–Pass–Pass，南家選 Pass 或重開賭倍；Pass 時東家打未賭倍 2♠，重開賭倍時由西家開始做四家全資訊、保留叫序的續叫 Par 搜尋，另有東西不賭倍南北三線八張配合（王牌 3–2，或 3–2 與 4–1）兩種保護假設。先看 `metadata.json`（種子、樣本數、停止規則、引擎識別與雜湊、主要結果）、`audits/summary.json`（三種假設的平均 IMP、95% 區間、BAM、勝和負、分組貢獻與 IMP 分布）與 `data/results.csv`（逐副結果，欄位說明在 `data/schema.json`，文章牌例在 `data/examples.json`）；篩牌條件在 `source/filters/rules.json`，各項檢查在 `audits/`。檢查與重新計算：`pip install -r source/requirements.txt` 後，`sha256sum -c MANIFEST.sha256`，`python3 source/reproduce.py --mode verify`（只讀資料，核對雜湊、牌張、篩牌、叫序、計分與統計），`python3 source/reproduce.py --mode tests`（編譯 C++17 續叫搜尋並跑窮舉對照），`python3 source/reproduce.py --mode sample --output <新目錄> --count 200`（從種子重抽前 200 副重算並逐列比對）；以上三個已實際跑過。`python3 source/reproduce.py --mode full --output <新目錄>` 會從種子重抽一萬副並全部重算，這個入口沒有實際跑過（資料本身就是同一套程式的完整執行結果）。
