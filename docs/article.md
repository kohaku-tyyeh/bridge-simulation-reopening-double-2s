北家是同伴，由他發牌；南北無身價，東西有身價。我們坐南家，拿著這手 11 HCP 的牌：

> **♠ 3　♥ 9754　♦ AKT8　♣ A764**

叫到：

| 北家（同伴） | 東家 | 南家（我們） | 西家 |
| :---: | :---: | :---: | :---: |
| Pass | 1♠ | 賭倍 | Pass |
| 1NT | 2♥ | Pass | 2♠ |
| Pass | Pass | ？ | |

東家叫出黑桃與紅心，西家在兩門高花之間選了黑桃，叫牌即將停在 2♠。我們已經在一線賭倍過一次，紅心四張被東家叫走，現在可以 Pass 讓東家打 2♠，也可以重開賭倍，讓同伴決定罰放或轉叫。我用一萬副符合這個叫序的牌，逐副比較兩種選擇。結論是重開賭倍較好：以 IMP 計平均每副多 0.22 IMP，以 BAM 計得分率 66.585%。收入主要來自罰 2♠ 與轉打我方的部分合約，失分則集中在我方找不到配合而宕約，以及讓東家叫到成局。

## 1. 比較方式與結論
Pass 時，叫牌結束，東家打未賭倍的 2♠，以雙夢家墩數計分。賭倍時，由西家開始續叫，四家都可以採取任何合法叫品，再以雙方都看得到四手牌的搜尋，求出雙方的最佳後續結果，下文稱為續叫 Par。每副牌把「賭倍後的續叫 Par 分數減去 Pass 的分數」換算成 IMP 後平均，正值代表賭倍較好；BAM 只和 Pass 比較，勝 1、和 ½、負 0。

續叫 Par 只記錄搜尋找到的一條叫牌路徑。Handviewer 裡賭倍之後的叫序就是這條路徑，中間的叫品沒有約定上的意義，例如北家的 2NT 不代表任何特定牌型，東西雙方也可能出現一長串扣叫；能拿來讀的是最後的合約、莊家與分數。雙方全資訊也代表同伴總能選到最好的罰放或轉叫，對手也總能找到最好的競叫，這兩種誤差在實戰中的方向無法事先判斷。

**原始續叫 Par 的結果**：

| 項目 | 數值 |
| :--- | ---: |
| 平均 IMP | +0.2209 |
| 95% 抽樣區間 | +0.124～+0.320 |
| BAM 得分率 | 66.585% |
| 賭倍勝／和／負 | 6,127／1,063／2,810 |

平均 IMP 的 95% 抽樣區間整段大於零。BAM 與 IMP 的差距很大，原因在第 5 節：大量牌例中賭倍只多贏 10 分，IMP 是 0，BAM 卻記一勝。Pass 的基準本身也不差，東家 2♠ 在 27.82% 的牌宕約，Pass 時我們已經拿到正分。

以下由簡單到複雜看賭倍會遇到的四種情形：同伴罰放、轉打我方的部分合約、找不到配合，以及讓東家叫到成局。牌號是本次一萬副樣本的編號；每副牌都有兩個 Handviewer，分別是 Pass 與賭倍到底的完整叫牌，可以按 DD 看雙夢家打法。

## 2. 最簡單的情形：同伴罰放，2♠X 宕約
同伴拿著四、五張黑桃，又沒有在第一輪主動處罰時，重開賭倍讓他有機會罰放。原始續叫 Par 中，2♠X 是最佳合約之一的牌有 2,467 副。東家宕一時，賭倍把 +100 變成 +200，多 3 IMP，這類牌有 2,063 副；宕二時 +200 變成 +500，多 7 IMP；宕三時 +300 變成 +800，多 11 IMP。

## 3. 轉打我方的部分合約
同伴不能罰放時，賭倍也讓我們有機會找到自己的合約。南家四張紅心已經被東家叫走，能打的通常是低花：續叫 Par 中，最佳合約只有我方合約、而且能成約的牌有 1,398 副，最常見的是南家 3♣ 的 536 副與北家 3♦ 的 532 副，其次是北家 2NT 的 213 副。這組牌大多是 Pass 時東家 2♠ 成約 −110，賭倍後我方 3♣ 或 3♦ 成約 +110，多 6 IMP，共 1,215 副。

## 4. 會出問題的地方：找不到配合，或讓敵方叫到成局
賭倍的大失分有兩個來源。第一是我方沒有好的合約：續叫 Par 中最佳合約只有我方合約、而且全部宕約的牌有 4,339 副，最常見的是北家 2NTX 的 2,256 副，其次是北家 2NT 的 701 副；其中 1,674 副，南北在任何花色都沒有八張配合。第二是東家拿著額外牌力，被賭倍之後叫到成局：最佳合約是東西成局而且成約的牌有 375 副，其中東家 4♠ 有 325 副，這組牌每副至少輸 10 IMP。

## 5. 全樣本：收益與損失從哪裡來
把原始續叫 Par 的每副牌，按最佳合約的集合分成互不重疊的七組。各組對平均 IMP 的貢獻，是該組 IMP 總和除以一萬，七組相加就是全樣本的平均。

**各組對平均 IMP 的貢獻**：

| 組別（依最佳合約分類） | 副數 | 對平均 IMP 的貢獻 |
| :--- | ---: | ---: |
| 敵方 2♠X 是最佳合約之一 | 2,467 | +0.9113 |
| 只有我方合約，能成約 | 1,398 | +0.8573 |
| 我方與敵方合約同為最佳 | 208 | +0.2020 |
| 敵方其他合約，宕約 | 128 | +0.0295 |
| 敵方部分合約，成約 | 1,085 | −0.0590 |
| 敵方成局，成約 | 375 | −0.3756 |
| 只有我方合約，全部宕約 | 4,339 | −1.3446 |
| 合計 | 10,000 | +0.2209 |

罰 2♠ 與我方成約兩組合計 +1.7686，被我方宕約與敵方成局兩組抵掉大半。「我方與敵方合約同為最佳」主要是北家 3NT 成約的 161 副，這組牌每副贏 7 或 11 IMP。「敵方部分合約」幾乎都是東家改打 3♠ 成約，共 955 副，−140 比 Pass 時的 −110 只差 30 分，多數是 0 IMP，所以這組副數不少，失分卻很小。

「只有我方合約，全部宕約」這組副數最多，但不全是失分。其中 1,444 副的結果是 −100，例如北家 2NTX 宕一或 2NT 宕二，對 Pass 時東家 2♠ 成約的 −110 反而多 10 分，IMP 是 0；真正失分的是被賭倍後宕二以上的牌，輸 8 IMP 以上的有 827 副。

**賭倍減 Pass 的 IMP 分布**：

| IMP | 副數 |
| :--- | ---: |
| −10 以下 | 461 |
| −9～−8 | 744 |
| −7～−1 | 1,605 |
| 0 | 2,513 |
| +1～+7 | 4,467 |
| +8 以上 | 210 |

賭倍的收入大多是小額的 +3 與 +6，輸的時候卻常是 −8 到 −10。輸 8 IMP 以上的牌有 1,205 副，其中我方宕約 827 副、敵方成局 375 副；贏 8 IMP 以上的只有 210 副。輸 10 IMP 以上的 461 副裡，敵方成局占 375 副。

BAM 與 IMP 的差距也來自這種分布。BAM 只看勝負，賭倍贏 10 分與贏 500 分都是一勝；原始分數上賭倍勝出、IMP 卻是 0 的牌有 1,450 副，其中 1,444 副是 −100 對 −110。以原始分數平均，Pass 每副 −58.79 分，賭倍 −56.42 分，只差 2.38 分，但賭倍在 61.27% 的牌勝出。用 IMP 計分時，賭倍的優勢就小得多。

## 6. 保護假設：敵方不賭倍我方三線八張配合
原始續叫 Par 是全資訊搜尋，我方合約會宕約時，敵方看得到四手牌，該賭倍就賭倍。實戰中，我方在三線打有王合約、恰好八張配合、敵方王牌 3–2 分配時，敵方常常不會賭倍，因為賭倍的收益只有一點點，風險卻可能是讓我方成約加倍。為了看結果對這一點有多敏感，我另外跑了兩種保護假設：「只保護 3–2」是我方三線有王合約、恰好八張配合、敵方王牌 3–2 時，敵方不賭倍；「保護 3–2 與 4–1」再加上敵方王牌 4–1。3NT、其他線位，以及 5–0 分配不在保護範圍內。兩種保護假設都重新搜尋整棵續叫樹，而不是只把最後合約的賭倍拿掉。

| 假設 | 平均 IMP | 95% 抽樣區間 | BAM 得分率 |
| :--- | ---: | ---: | ---: |
| 原始續叫 Par | +0.2209 | +0.124～+0.320 | 66.585% |
| 只保護 3–2 | +0.4276 | +0.330～+0.524 | 67.865% |
| 保護 3–2 與 4–1 | +0.6295 | +0.534～+0.724 | 69.520% |

| 假設 | 賭倍勝 | 和 | 賭倍負 |
| :--- | ---: | ---: | ---: |
| 原始續叫 Par | 6,127 | 1,063 | 2,810 |
| 只保護 3–2 | 6,197 | 1,179 | 2,624 |
| 保護 3–2 與 4–1 | 6,291 | 1,322 | 2,387 |

只保護 3–2 時，有 807 副牌的分數改變，最常見的是賭倍後的 −100 變成 −50，共 602 副，每副多 2 IMP。這些牌不全是同一個合約不再被賭倍：我方三線低花不會被賭倍之後，續叫路徑也會跟著改變，例如北家 2NTX 宕一變成 2NT 宕一。保護 3–2 與 4–1 時，改變的牌增加到 1,507 副，其中 1,041 副是 −100 變 −50。擴大保護範圍後，沒有任何一副牌的分數下降；但輸 10 IMP 以上的 461 副在三種假設下都一樣，因為這些牌是敵方成局，或我方不在保護範圍內的大宕約，例如北家 2NTX 宕四。

## 7. 模型與篩牌條件
每副牌先固定南家的 13 張，對其餘 39 張均勻洗牌，再按下列條件剔除不符合叫序的牌。篩牌時沒有參考雙夢家墩數、續叫 Par 或賭倍是否獲利。

**東家**：至少五張黑桃、至少四張紅心，黑桃不少於紅心。再叫 2♥ 的點力依兩門長度分檔：

| 黑桃–紅心長度 | HCP 範圍 |
| :--- | :--- |
| 5–4 | 15–17 |
| 5–5 或 6–4 | 13–16 |
| 6–5 | 11–15 |
| 更長、至少 6♠5♥ 的雙套 | 11–15 |

恰好 7♠4♥ 的牌排除，表上沒有列的牌型不收。東家最後 Pass 2♠ 時，未經調整的基本失墩數（LTC）至少 5。15 點以上的牌，即使四張紅心很差，也不因為牌組品質排除。

**西家**：2♠ 視為在同伴兩門高花中選擇黑桃，只收黑桃不少於紅心、黑桃至多四張的牌。點力上限如下：

| 黑桃支持 | HCP 上限 |
| :--- | ---: |
| 0–2 張 | 7 |
| 三張且平均型 | 5 |
| 三張不平均，或四張 | 4 |

平均型指 4333、4432、5332。西家第一輪的 Pass 與後來的 2♠，兩者的限制同時適用。

**北家 1NT**：6–10 HCP；每門 2–5 張，紅心至多三張，允許 5422。黑桃至少有 A、Kx、Qxx、Jxxx 其中一種。北家有五張低花時，若符合 6–8 HCP、5422 牌型，或那門五張低花含 AKQJ 中至少兩張，三者任一，就視為會叫低花而不叫 1NT，從樣本排除；但黑桃有 A、有 KQ，或四張以上黑桃含 QJ 時，仍然叫 1NT。北家第一輪的 Pass 沒有另外設限。

| 黑桃張數 | 單套完整 KnR | 其他條件 |
| :--- | ---: | :--- |
| 四張 | ≥5.65 | 整手 ≥8 HCP；旁門至少一張 A 或 K |
| 五張 | ≥6.25 | 整手 ≥8 HCP；有黑桃 A 或 KQ 時，7 HCP 即可 |

五張黑桃另外沿用四張的規則：刪去任一張黑桃後，剩下的四張若符合四張的處罰條件，這手牌也排除；計算整手點力時，扣掉被刪那張大牌的 HCP。南家重開賭倍之後，北家是否罰放，交給續叫 Par 決定。

固定南家 11 點、北家至多 10 點、西家至多 7 點，實際入選的牌中東家至少 12 點。共洗牌 22,555,277 次，取得 10,000 副符合條件的牌，接受率約 0.0443%，每副權重相同。

## 8. 結論
在這套叫牌模型下，南家應該重開賭倍。以 IMP 計，原始續叫 Par 平均每副多 0.22 IMP，95% 抽樣區間整段大於零；敵方不賭倍我方三線八張配合時，收益增加到 0.43 或 0.63 IMP。以 BAM 計，賭倍的得分率在三種假設下都超過 66%。

收入來自兩處：同伴有黑桃時罰放 2♠，以及同伴有低花配合時轉打 3♣ 或 3♦。代價也很明確：同伴沒有配合時，我方常在二、三線被賭倍宕約；東家牌力偏強時，賭倍給了他叫到成局的機會，每副輸 10 IMP。單看一副牌，賭倍通常是小贏；輸的時候輸得多，但贏的次數夠多，平均仍是正的。

## 計算與閱讀註記
- 抽樣：固定南家 13 張後，對其餘 39 張做均勻隨機洗牌，剔除不符合叫牌模型的牌，取滿一萬副即停止；停止條件與牌局結果無關。亂數種子 2026111108。
- 雙夢家：使用 DDS 2.9.0，由 endplay 0.5.12 附帶的 libdds.so 提供。每副計算四個莊位乘以五種王牌，共 20 個雙夢家墩數，包含最佳首攻。
- Pass 與賭倍：Pass 時東家打未賭倍的 2♠，以東家打黑桃的雙夢家墩數、東西有身價計分。賭倍時由西家開始續叫，四家都可以採取任何合法叫品。
- 續叫 Par：用自寫的 C++ minimax 搜尋器讀取雙夢家墩數表，保留目前叫序、各花色已知的第一叫牌者與身價，求雙方全資訊下最佳的後續分數。每副只保存一條最佳叫牌路徑；最佳合約是否唯一有記錄，最佳叫牌路徑是否唯一則沒有記錄。
- 保護假設：適用範圍是我方任一莊位、任何花色作王的三線八張配合，敵方王牌 3–2，或 3–2 與 4–1；3NT、其他線位、5–0 分配，以及我方賭倍敵方，都不在範圍內。保護假設沒有估計真人實際不賭倍的頻率。
- KnR：只取單門牌質與大牌部分的完整分數，不分攤整手的調整值。四張 KQT2 為 5.65，五張 KQT52 為 6.25。公式參考 Richard Pavlicek 的[KnR 公式說明](https://www.rpbridge.net/8j19.htm)。
- 分組：第 5 節的七組依原始續叫 Par 的最佳合約集合劃分，並以雙夢家墩數判斷成約或宕約。
- 抽樣區間：95% 抽樣區間以 10,000 次 bootstrap 估計，只反映這套模型下的抽樣誤差，不包含叫牌篩選的偏差、雙夢家與真人打牌的差異，以及全資訊續叫與實際續叫的差異。
- 檢查：一萬副全部逐副重算過分數、IMP、BAM、雙夢家墩數與合約的對應、叫序合法性，以及 52 張牌完整；文中的平均值、勝負數與分組貢獻都與重算結果一致。
- 資料：一萬副牌、逐副結果、篩牌與搜尋程式、各項檢查紀錄，都放在 [kohaku-tyyeh/bridge-simulation-reopening-double-2s](https://github.com/kohaku-tyyeh/bridge-simulation-reopening-double-2s)。逐副結果在 data/results.csv，篩牌條件在 source/current/rules.json，三種假設的統計在 audits/current/summary.json 與 audits/current/no_double_policy/summary.json。
